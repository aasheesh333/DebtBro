# Play Store Release Notes — DebtPayoff Pro

Single source of truth for Google Play Console "What's new" copy.
Play Store hard limit: **500 chars** per language for the "What's new"
section. Long-form changelog lives at the bottom for internal/PR use.

## How to use

1. Open Play Console → your app → **Production** (or Internal testing) →
   **Create new release**.
2. Upload `app-release.aab` from the matching GitHub Release
   (https://github.com/aasheesh333/DebtBro/releases/latest).
3. Under **Release notes**, paste the per-language block from the
   **Production copy (≤500 chars)** section below into each language's
   textbox. If a language isn't listed, paste the English (en-US) version.
4. Review the rollout %, then **Start rollout to Production**.

## Internal changelog (long-form, not for Play Store)

### Added
- **Android 16 (API 36) target** — `compileSdk`/`targetSdk` 35 → 36.
- **Sort debts** in the debt list (amount, interest rate, due date, name).
- **Contact Picker bottom sheet** — pick a contact directly when creating
  splits instead of typing a name/number.
- **Split edit + delete** — long-awaited. Edit any split, delete it, with
  sync-safe unique index to stop duplicate Firestore entries.
- **Live currency conversion** on Dashboard + Analytics using
  `open.exchangerate-api.com`, auto-selected by device locale.
- **AI insight caching** keyed by a debts-checksum, so switching tabs no
  longer re-fetches the Gemini insight.
- **Engagement push notifications** via `EngagementWorker`, plus
  due-date reminders rebuilt on top of `DebtDueDateReminderWorker`.
- **5 new i18n keys across 25 languages** for the new auth flow.

### Changed
- App display name → **DebtPayoff Pro** everywhere (was "DebtBro").
- Replaced the old combined `AuthScreen`/`AuthViewModel` with separate
  **SignUp** and **SignIn** screens + ViewModels + a shared
  `authSharedUi.kt`. Onboarding now drops the in-flow name/auth pages
  (4 pages instead of 6) and routes first-time users straight to SignUp.
- Account-deletion grace window **30 min → 24 h**, matching the live
  Privacy Policy / Delete-Account / Help-and-Support pages.
- Notification icon now uses a proper AndroidAssetStudio-generated
  monochrome (was reusing the full-color logo, which Android tints
  incorrectly and produces a blank square on some OEMs).
- App icon rebrand — logo used as launcher, Play Store, and
  notification icon consistently.
- AdMob banner ad in the Scaffold, app-open ad, UMP consent flow.
  Interstitial preloads on save; rewarded ad gates the AI "Take"
  button after 5 free outs per day (mirrors the Analytics AI insight
  gate).
- Dependency bumps (gradle/libs.versions.toml):
  AGP 8.6 → 8.12, Kotlin 2.0 → 2.1.21, Compose BOM 2024.10 → 2025.03,
  Room 2.6.1 → 2.7.1, Firebase BOM 33.7 → 33.12, Credentials 1.2.2 →
  1.6.0, navigationCompose 2.7.7 → 2.8.5, workmanager 2.9 → 2.10,
  datastore 1.1.1 → 1.2.1, admob 23.6.0 → 24.0.0, coil 2.6 → 2.7,
  coroutines 1.8.1 → 1.10.2, lifecycle 2.8.2 → 2.8.7, coreKtx
  1.13.1 → 1.18.0. `kotlinOptions { jvmTarget }` →
  `kotlin { compilerOptions { jvmTarget } }` (new DSL).

### Fixed
- **Auth**: signedIn flow was not wiring through to the Dashboard;
  Google Credential unwrap crashed on some devices; SignUp race that
  could leave a phantom email account; fields not clearing on
  success; USER_NAME not persisting after Google sign-in.
- **Account deletion**: cross-user grace-period alert when another
  user had a pending deletion (UID-scoped timestamp now); Firebase
  account killed too early after "Delete now" so the 24h re-login
  alert never fired; `firestore.rules` now splits read/write on
  `deletionRequests` so reads succeed; `requestImmediateDeletion` was
  calling suspend functions from a non-suspend context.
- **CSV export**: crash on devices where the FileProvider didn't expose
  `Download/DebtPayoffPro` — added to FileProvider paths.
- **Split**: duplicate entries coming back from Firestore sync —
  added a unique index + `IGNORE` on insert; double-inset above the
  bottom nav (inner Scaffold dropped); form not clearing after
  `createSplit`; double-tap on `createDebtsFromSplit` could fire twice.
- **Currency**: wrong endpoint on `open.exchangerate-api.com`; the
  `asMap` sidestep avoids the previous Gson-deserialize crash.
- **Dashboard**: wrong `LifecycleResumeEffect` overload signature,
  and the trailing lambda wasn't returning the `onPauseOrDispose`
  result (lifecycle hook wasn't detaching correctly).
- **Ads**: unresolved `adapterStatusByAdNetwork` reference in the
  MobileAds init log; ad loads retried on the wrong thread from
  `NetworkCallback`; missing `AD_ID` permission; missing
  `lifecycle-process` dep for `ProcessLifecycleOwner`.
- **AddDebt**: past dates were rejected silently inside the picker;
  switched to a post-confirm rejection so users see a clear message.
  Custom emoji capped to 8 chars to keep cards readable. Due date
  restricted to today-or-future.
- **Release pipeline**: VERSION_CODE wasn't wiring through to the
  release build; OneSignal API key leaked into logs; large-icon
  fetch failing silently; ONESIGNAL_API_KEY restored for dashboard
  push usage.

### Removed
- `accompanist-permissions` (no longer needed after Credentials
  library adoption).
- Inline `Login Data` migration shim (now handled by Credentials API).
- Old onboarding `Page5aName` + `Page6Auth` (auth lives in the new
  standalone screens).

### CI
- Read Gradle version from `gradle-wrapper.properties` instead of
  hardcoding 8.7, derive the Gradle extract folder from the zip name
  (was hardcoded to `gradle-8.7`).
- Hilt downgraded 2.60.1 → 2.56.2 for AGP 8.12 compatibility; KSP
  pinned to 2.1.21-2.0.1; `kotlin-metadata-jvm` overridden to 2.4.0
  for the Hilt KSP processor; Hilt extension 1.4.0 → 1.2.0;
  lifecycle 2.11.0 → 2.8.7 — all deptree fixes for AGP 8.12.
- `kotlinOptions { jvmTarget }` migrated to
  `kotlin { compilerOptions { jvmTarget } }` DSL (deprecation
  warning under the new Kotlin plugin).
